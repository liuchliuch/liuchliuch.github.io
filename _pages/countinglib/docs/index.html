COUNTING COMPLEXITY IN LEAN

Counting complexity in Lean

CountingLib brings finite counting, weighted partition models, algorithms, and classification results into one reusable Lean 4 library.

Start with a small interface

Use a focused import for a definition or algorithm. Add a flagship module when you need a classification theorem. The Lean package is named countingComplexity; its public namespace is Counting.

import Counting.Foundation.Witness

open Counting.Foundation

example : countAccepted (fun b : Bool => decide (b = true)) = 1 :=
  countAccepted_singleton true

About this reference

The searchable API presents 333 selected declarations from 80 provider modules, organized into 30 contract families. It is an entry point to the library rather than an inventory of every internal declaration. Signatures come from recorded Lean environment exports; complete explicit types remain available alongside readable views.
